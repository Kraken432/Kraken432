## ◈ Featured Projects

<details>
<summary><strong>🔐 Cybersecurity Home Lab — Multi-VM Offensive & Defensive Environment</strong></summary>

<br/>

A production-grade, isolated penetration testing and threat detection laboratory built from the ground up on VirtualBox. Designed to simulate real-world attacker/defender scenarios across a host-only network.

| Attribute | Details |
|---|---|
| **Stack** | Kali Linux · Metasploitable 2 · Ubuntu (Wazuh SIEM) · Windows 7 VM · VirtualBox |
| **Network** | Host-only isolated network — 4-VM topology |
| **Exploits** | vsftpd 2.3.4 · UnrealIRCd 3.2.8.1 · Samba MS-RPC — all achieving root shell |
| **SIEM** | Wazuh 4.7.5 + Suricata 8.0.5 — live alert monitoring across all nodes |
| **Web Attacks** | SQL Injection (UNION-based) · Stored & Reflected XSS via DVWA |
| **Post-Exploitation** | Password hash dumping · John the Ripper offline cracking |
| **Repository** | [github.com/Kraken432](https://github.com/Kraken432) |

**Architecture:** Attacker machine (Kali) operates against Metasploitable 2 as the primary target. An Ubuntu node runs the Wazuh SIEM stack with Suricata as the IDS, ingesting logs from all machines and generating alerts on exploitation activity. The Windows VM serves as an additional target for credential attacks.

**Outcome:** Achieved full root compromise across three separate CVEs. Demonstrated end-to-end kill chain from reconnaissance → exploitation → post-exploitation → detection, all documented in a formal penetration test report.

</details>
